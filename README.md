<h1 align="center">AraBrief</h1>

AraBrief turns news about the topics you follow into short, AI-narrated briefings on your Windows desktop. Keep listening to music: when a briefing is ready, AraBrief lowers the volume of your selected music app, plays the news, and restores the volume afterward.

## Features

- **News that follows your interests** — topic-based Google News RSS discovery and article reading.
- **Briefings on a schedule** — prepare in the background, then play at the configured interval.
- **Music keeps playing** — volume control applies to the selected audio session, with a separate narrator volume.
- **A preview before you listen** — prepare a briefing without playback, then review its script and source links.
- **Pause and resume** — pause a briefing or its countdown while your music continues.
- **Polish and English** — interface and narration in either language, with an independent news country picker.
- **Desktop convenience** — system tray, optional Windows startup, and local caches for prepared text and audio.
- **Your own API key** — entered in a native Windows dialog and stored in Windows Credential Manager.

## How it works

1. Add your OpenAI API key, choose your topics and news country, and select a music app's audio session.
2. Start the schedule. AraBrief discovers articles, reads available content, and prepares a script and narration.
3. At the scheduled time, AraBrief lowers the selected session's volume and plays the completed briefing.
4. After playback, it restores the music volume and prepares for the next interval.

The first scheduled briefing waits a full interval. You can also prepare and listen manually. The voice is generated by AI, not a human narrator; source availability and the amount of usable material affect each briefing.

## Download

Get the Windows x64 installer from [the latest GitHub Release](https://github.com/apjanusz/ara-brief/releases/latest). In **Assets**, download the file ending in `x64-setup.exe`.

See [installation and first launch](docs/getting-started.md) for setup instructions. Current MVP installers are unsigned, so Windows may display a SmartScreen warning.

## Requirements and API costs

- Windows 10 or 11, x64.
- Microsoft Edge WebView2 Runtime; the installer downloads its bootstrapper if needed.
- Internet access for news discovery, article retrieval, and OpenAI services.
- Your own OpenAI API key, available API billing or credits, and access to the configured text and speech models.

**Text generation and speech synthesis incur OpenAI API charges**, including preparation without playback. API billing is separate from a ChatGPT subscription. Costs depend on the models, input and output, speech generated, and briefing frequency. Review [current API pricing](https://developers.openai.com/api/docs/pricing) and [OpenAI's billing explanation](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform).

The current speech adapter uses `gpt-4o-mini-tts`. OpenAI has announced its shutdown for **January 6, 2027**; see the [speech compatibility note](docs/troubleshooting.md#speech-model-availability) before relying on this version beyond that date.
